1 Install Prerequisites

Follow this sequence before starting API operations.

  1. Install Python 3.11+ and make sure python is on PATH.
  2. Install FFmpeg/FFprobe and confirm both commands resolve in terminal.
  3. In this repo run pip install -e ., then vra doctor to verify your configured engine and ASR servers.
  4. Run vra serve --bind <bind address> to keep this GUI active.
